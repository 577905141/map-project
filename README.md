# Local Landmarks Map

An interactive web map of 20 local places in Idaho Falls, Idaho, built with the ArcGIS Maps SDK for JavaScript.
**Live demo:** https://577905141.github.io/map-project/

## Features

- Color-coded markers for four categories: parks (green), museums (purple), schools (orange), and stores (red)
- Click a marker to see a popup with the place's name, type, and description
- Dropdown filter to show all places or only one category

## Built With

- HTML, CSS, and JavaScript
- ArcGIS Maps SDK for JavaScript 4.30

## How to Run

Visit the live demo above, or open `index.html` in a web browser.
